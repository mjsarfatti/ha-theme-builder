# Home Assistant Core Design System

This is the HA Core Design System imported from Claude Design.

## Contents

- **HA Core Design System.dc.html** - Main design system file (Claude Design format)
- **github.md** - Documentation of Material Design Icon references used
- **support.js** - Claude Design runtime support library (needed for .dc.html to work)

## About

This is the official Home Assistant color and token design system featuring:

- **Spacing, color & shape tokens** - Core design variables
- **Surfaces & dividers** - Background and separator colors  
- **Text colors** - Primary, secondary, and disabled text
- **Brand & status colors** - Primary, accent, error, warning, success, info
- **Neutral ramp** - Tunable foundation for all neutrals
- **Extended palette** - Full Material Design color set with contrast checking
- **Applied demo** - Real Home Assistant room card example

## How to Use

The design system is interactive and can be viewed in a modern web browser or in Claude Design.

To use it as a reference:
1. Open `HA Core Design System.dc.html` in a browser (requires `support.js` in the same directory)
2. Adjust palette settings using the UI controls
3. Copy generated theme values to your Home Assistant theme file
